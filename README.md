# Juan Camilo Vásquez Salazar — Academic Website

This folder contains a static version of the website that can be hosted free of charge with GitHub Pages.

## Publish it on GitHub Pages

1. Sign in to GitHub with the `Juanca42` account.
2. Create a new **public** repository named exactly `Juanca42.github.io`.
3. Choose **Add file → Upload files**.
4. Upload the five files in this folder to the repository root. Do not upload the ZIP file itself.
5. Commit the files to the `main` branch.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, select **Deploy from a branch**.
8. Select the `main` branch and the `/ (root)` folder, then save.
9. After a few minutes, visit `https://juanca42.github.io`.

## Edit the website

- **Text, links, sections, and office:** edit `index.html`.
- **Colors, fonts, spacing, photograph size, and mobile layout:** edit `styles.css`.
- **Photograph:** upload a new JPG using the exact filename `juan-camilo-vasquez.jpg` and replace the existing file.
- **CV:** upload a new PDF using the exact filename `Juan_Camilo_Vasquez_CV.pdf` and replace the existing file.

After every edit, select **Commit changes**. GitHub Pages will publish the update automatically, usually within a few minutes.

## Preview changes before publishing

For safer editing, create a new branch, make the changes there, and open a pull request. Merge the pull request into `main` only after reviewing the preview or the code changes.
